# Dream World

A 3D character / farm / build game — play in the browser on laptop or phone.

## Play online

After GitHub Pages is enabled, open:

**https://\<your-username\>.github.io/dream-world/**

## Play locally

```bash
python3 -m http.server 8765
```

Then visit http://localhost:8765 (or your laptop’s IP on the same Wi‑Fi).

## Phone controls

- **Left joystick** — move
- **Drag on the world** — look around
- **Use** — interact (leash, saddle, ride)
- **Jump / Run** — as labeled
- **Build / Inventory / Menu** — top-right buttons
- In build mode: tap to place, **Remove** to delete a wall

## Laptop controls

WASD move · Mouse look · Space jump · Shift run · E interact · B build · I inventory · Right-click remove
